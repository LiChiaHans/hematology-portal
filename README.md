# 血液科臨床資源入口網 (Hematology & BMT Clinical Portal)

整合血液科常用臨床工具、骨髓檢查預約系統、疾病個論與病人衛教資源的靜態入口網站。

## 包含項目
- **臨床工具與預約系統**
  - 骨髓檢查預約系統
  - BMT Protocol 產生器
  - 血液科照會罐頭（持續建置中）
- **疾病個論網站**（持續更新中）
- **病人衛教網站**
  - 血癌攻略
  - 淋巴癌攻略
  - 臺大醫院 癌症病人多元整合照護手冊

## 如何更新連結
直接編輯 [`config.js`](./config.js) 中的 `url` 與 `status` 欄位（將 `status` 設為 `"active"`）即可啟用或新增項目。
